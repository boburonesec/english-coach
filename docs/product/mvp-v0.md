# MVP v0 contract

MVP v0 tests whether interesting conversations create regular use, whether focused coaching improves active English, and whether the product can identify the next useful practice. This document describes the intended MVP; the repository bootstrap does not implement it.

## Core session

1. The learner receives three conversation options and chooses one.
2. A short, voice-first context sets up the conversation; a transcript is optional.
3. The learner gets a short period to think before a dynamic conversation begins.
4. Normal grammar corrections do not interrupt speaking. A hint appears only when requested.
5. After the session, a detailed review can identify many observations.
6. The coach chooses only one to three high-value learning priorities.
7. The learner actively practices those priorities.
8. Later sessions recall and reuse the learning in different contexts.

## Learning principles

- **See everything, work on very little.** Broad analysis should produce narrow action.
- **Communication first.** Prioritize changes that improve meaning, participation, and confidence.
- **Active recall.** The learner should produce language, not only recognize advice.
- **Reuse across contexts.** A pattern learned in one topic should be tested elsewhere.
- **Stable performance defines mastery.** One successful use is evidence, not proof; mastery requires reliable performance across contexts.

## Session intensity

- **Survival:** low load, shorter turns, and more support when the learner needs to stay in the conversation.
- **Normal:** balanced conversational challenge and support for regular practice.
- **Deep:** longer, more demanding reasoning and sustained expression.

Adaptive intensity is a conceptual direction, not part of the first implementation slice.

## Non-goals

- External Slack, Codex, Claude, or Gemini integrations
- Social features
- Heavy gamification
- A full CEFR dashboard
- A full vocabulary course
- Many exercise formats
- Microservices
